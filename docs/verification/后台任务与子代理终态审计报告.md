### 4.3 是否可安全继续 / 应否终止

| 判据 | 结论 |
|---|---|
| 资源占用 | 仅 16 MB 内存、无 CPU 活动（空闲 HTTP 服务），可长期挂机 |
| 数据安全 | 只读服务（SimpleHTTP 无写接口），不修改任何文件 |
| 内容正确性 | 与主仓库最新 `site/` 字节一致，预览 = 即将发布内容 |
| 暴露面 | 绑定 0.0.0.0（非仅 127.0.0.1），局域网内可见；文档站为公开内容，风险低；如需更严格可改 `--bind 127.0.0.1` 重启 |
