## 4.1 章节定位与引擎架构

`Berechnung LU` 是 Gebäude-Tool 中唯一的"物理"计算引擎：对**一台**空气处理机组（AHU）按**温度区间法**（temperature-bin method）做全年焓湿计算。要点：

1. **一实例一系统**：`Berechnung LU!A6 = Lüftung!A32` 只承载"当前系统"（示例 = LA01）。16 个系统（LA01…LA16）的循环由宏 `Lüftung_Resultate`（`Lüftung_Resultate.bas`）实现：把 `Lüftung!A7:Z7` 复制到 `A32:Z32` → 重算本表 → 把结果行 7 与模板行 32 的对应值复制回系统行（`A7`、`G32`、`I32`、`O32:X32`）→ 重复 16 次。
2. **双块结构**：IST 块（行 121–181，61 个区间，输入取 E 列）与 SOLL 块（行 189–249，输入取 F 列）结构相同；**本文件中 SOLL 块处于休眠**（气候单元格为 0、气压引用 `#REF!`、`K82/M82/P82/R82 = 0`），所有结果来自 IST 块。SOLL 块是"目标状态"的对照（示例建筑中未填 F 列输入）。
3. **区间气候数据**：61 个室外温度区间 t_A = −25…+35 °C（每 1 K 一档），每档给出年小时数、相对湿度与含湿量（第 6 章）。
4. **状态链**：AUL（室外）→ 防冻预热 → WRG（热回收）→ MIL（混合/新风）→ 冷盘管链（A/C/D1/D2）→ 加热/加湿（E/F/G）→ ZUL soll/ist → 房间/排风 → 焓差 → 每小时能量 × 区间小时数 → 年能量。

## 4.4 公式 1 — 区间小时数（运行小时折算）

**数学形式**：区间 k（温度 t_A = k °C，k = −25…35）的年运行小时数：

$$
B_k = \frac{O_{k+30}}{8760}\cdot t_{VL,V} \quad[\mathrm{h/a}]
$$

其中 $O_{k+30}$ = `Klimadaten!O5:O65`（区间小时数，见第 6 章），$t_{VL,V}$ = `Berechnung LU!K68`（风量基准全负荷小时，第 3 章）。

**工作簿实现**（`Berechnung LU!B121`，t_A = −25 °C）：`=Klimadaten!O5/8760*$K$68`（区间 k ↔ Klimadaten 行 k+30）。

**单位**：h/a。**性质**：$\sum_k B_k = t_{VL,V}$（=3900 h 示例）——把 SIA 全负荷小时"摊回"到各温度区间，作为每档的全年运行时间；这也是"温度区间法"与"全负荷小时法"的衔接点。

**验证**：k = −10（行 136）：`B136 = 6/8760×3900 = 2.671 h` ✓；k = 22（行 168）：`59.6575 h` ✓。

**假设**：① 区间小时数分布与系统运行时段独立（运行不改变区间分布的形状，只压缩总时长）；② 区间温度取区间下限。

**适用范围**：IST 块全部 61 行；SOLL 块（行 189–249）同构但休眠。

**单元格出处**：`Berechnung LU!B121:B181`；气候源 `Klimadaten!O5:O65`；`K68`。

## 4.5 公式 2 — 室外状态与防冻预热

**数学形式**：室外状态（含湿量 $x_A$、室温处相对湿度 $\varphi_R$）：

$$
x_A = \text{Klimadaten!Q}_{k+30}\ [\mathrm{g/kg}],\qquad
\varphi_R = \min\!\big(1,\ \varphi(t_{Raum}, x_A, p)\big)
$$

防冻预热（仅当 $t_A \le t_{VS}$，即 `A{n}<=$E$33`）：

$$
t_{VS} = t_A + \frac{P_{VS}\cdot 3600}{\dot V_{Jahr}\,\rho\, c_{pl}} \quad[\mathrm{°C}]
$$

**工作簿实现**：`C{n} = Klimadaten!Q{k+30}`；`E{n} = MIN(100%,RelFeuchte(BR{n},C{n},$N$19))`；`G{n} = IF(A{n}<=$E$33,(IF($E$32=$I$32,DB{n},IF($E$32=$I$33,DC{n},0))*3600)/($K$70*$N$20*$N$23)+A{n},A{n})`；`DB{n} = IF(A{n}<=$E$33,$F$113,0)`（开关式）；`DC{n} = IF(A{n}<=$E$33,ABS($K$70*$N$20*$N$23*MIN(ABS(A{n}-$E$33),ABS($E$40-$E$33))/3600),0)`（可变式）。

**单位**：g/kg；–；°C。

**推导**：$\varphi_R$ 用 `RelFeuchte`（第 1 章公式 5）在室温（`BR`，温度曲线）下反算室外含湿量的相对湿度——即"房间湿度跟随室外含湿量"的简化模型（无独立湿源时）。防冻功率 `F113 = ṁ·cp·(t_设计−t_边界)/3600`（kW），预热温升 = P/(ṁ·cp)。

**假设**：示例中 `E32=0`（防冻关）、`E33=0`，故 `G{n} = A{n}`（不预热）；房间湿度带 [E50, E48] = [0, 1]（不约束）。

**适用范围**：61 个区间；防冻分支仅 t_A ≤ E33 时激活。

**单元格出处**：`Berechnung LU!C121:C181、E121:E181、G121:G181、DB121:DB181、DC121:DC181`、`F113`。

## 4.6 公式 3 — 热回收 WRG（固定效率与调节效率）

**数学形式**：设排风（Abluft）温度 $t_{AB}$（=`BU`，= 室温，Quellluft 时 +2 K）、室外温度 $t_A$、WRG 标称效率 $\eta_0$（=`E28`=0.8）：

$$
t_{WRG,0} = t_A + \eta_0(t_{AB}-t_A);\qquad
t_{WRG,reg} = t_A + \varepsilon(t_{AB}-t_A),\quad
\varepsilon = \max\!\Big(\frac{t_{ist}-t_A}{t_{AB}-t_A},\ 0\Big)
$$

其中 $t_{ist} = \min(t_{WRG,0},\ t_{ZUL,soll})$（不过热回收——夏季全旁通时 $\varepsilon=0$）。

**工作簿实现**：
- `I{n} = $E$28*(BU{n}-A{n})+A{n}`（固定效率）；
- `J{n} = IF(F{n}=0,MIN(I{n},BJ{n}),I{n})`（限幅；`F{n} = IF(H{n}<=0,IF(BU{n}<A{n},1,0),0)` 为夏季冷却标志）；
- `K{n} = IF($E$30=$S$20,$E$28,MAX(IF(AND($E$31=$S$20,F{n}=1),0,IF(A{n}=BU{n},0,(J{n}-A{n})/(BU{n}-A{n}))),0))`（**调节效率**；E30="ja" 旁通存在 → 用比值式）；
- `L{n} = IF($E$30=$S$21,K{n}*(BU{n}-A{n})+A{n},I{n})`（旁通后的送风侧温度）；
- `M{n} = IF($E$28=0,C{n},(K{n}/$E$28*$E$29)*(BW{n}-C{n})+C{n})`（湿度回收，E29=0 → M = x_A）。

**单位**：°C；ε [–]。

**推导**：效率定义式 $\varepsilon = (t_{nach}-t_{vor})/(t_{quelle}-t_{vor})$ 的反解；旁通调节把 ε 从标称值降到"恰好达到送风设定温度"所需值，夏季（室外 ≥ 设定）为 0（全旁通）。**验证**（行 168，t_A=22 °C，t_AB=24 °C，t_ZUL,soll=20 °C）：`I168 = 22+0.8×(24−22) = 23.6` ✓；`J168 = MIN(23.6, 20) = 20`；`K168 = (20−22)/(24−22) = −1 → MAX(…,0) = 0`（全旁通）✓；`L168 = 22` ✓。

**假设**：效率对温度差线性（无冰点/结露降效）；KRG（E31）存在且夏季时 ε 强制 0；湿度回收与 ε 成比例（E29 缩放）。

**适用范围**：冬夏两季通用；示例（E30="ja"）走调节分支，E30="nein" 时用固定 η0。

**单元格出处**：`Berechnung LU!F121:F181、H121:H181、I121:I181、J121:J181、K121:K181、L121:L181、M121:M181`、`BU121:BU181`（排风温度）、`BW121:BW181`（排风含湿量）。

## 4.7 公式 4 — 混合空气 MIL（新风比与旁通）

**数学形式**（焓控分支，E36≠D36 时温度控分支激活，见 4.10）：新风比 $\gamma_{min}=\text{E34}$、$\gamma_{max}=\text{E35}$（示例均 1）：

$$
h_{MIL} = \gamma\, h_{nWRG} + (1-\gamma)\, h_{AB};\qquad
u = 1 - \frac{h_{soll}-h_{AB}}{h_{nWRG}-h_{AB}};\qquad
t_{MIL} = t_{nWRG}(1-u)+t_{AB}\,u
$$

（u = 回风份额，使 $h_{MIL}$ 收敛到目标 $h_{soll}$；示例 γ=1 → u=0，MIL = 纯新风。）

**工作簿实现**：`N{n} = EnthalpieA(L{n},M{n},$N$19)*$E$35+(1-$E$35)*EnthalpieA(BU{n},BW{n},$N$19)`（焓，γ_max）；`O{n}` 同构 γ_min；`P{n} = 1-IF(EnthalpieA(L{n},M{n},$N$19)=S{n},$E$35,(S{n}-EnthalpieA(BU{n},BW{n},$N$19))/((EnthalpieA(L{n},M{n},$N$19)-EnthalpieA(BU{n},BW{n},$N$19))))`；`Q{n} = L{n}*(1-P{n})+BU{n}*P{n}`；`R{n} = M{n}*(1-P{n})+BW{n}*P{n}`；`S{n} = MIN(MAX(N{n},BM{n}),O{n})`（目标焓 = h_ZUL,soll，夹在 [h_MIL,min, h_MIL,max]）；温度控分支同构：`T{n} = MIN(L*E35+BU*(1-E35))`（MIN 单参为 no-op）、`U{n}`、`V{n} = 1-IF(L{n}=W{n},$E$35,(W{n}-BU{n})/(L{n}-BU{n}))`、`W{n} = MIN(MAX(T{n},BJ{n}),U{n})`、`X{n} = M{n}*(1-$V{n})+BW{n}*$V{n}`、`Y{n} = EnthalpieA(W{n},X{n},$N$19)`。

**单位**：kJ/kg；°C；g/kg。

**推导**：混合定律（能量与质量守恒）：$h = \sum w_i h_i$、$t = \sum w_i t_i$、$x = \sum w_i x_i$；回风份额 u 由目标焓反解。

**假设**：示例 γ_min=γ_max=1（无回风）；焓控分支（P/Q/R）仅在 `$E$36=$D$36` 时参与下游，温度控分支（V/W/X/Y）恒被计算且被 Fall 检测器 AW 使用（E36="Temperatur"）。
