# 第 3 章 通风全负荷小时（Volllaststunden Lüftung）

> 核心区域：`Std!A1:V50`（数据表）、`Berechnung LU!K68/K69`（按 Regelung 查表）、`Lüftung!J7:J22`（Regelung 输入）、`Lüftung!K7:K22`（反推全负荷小时）
> 数据来源：Raumdatenblätter `Volll_Lüft` 表（`Std!L2` 注释："Quelle: SIA2024_Raumdatenblätter > tblVoll_Lüft"）

## 3.1 章节定位

通风系统的风机年电能 $E_{fan} = P_{fan}\cdot t_{VL}$ 需要**全负荷小时**（Volllaststunden）$t_{VL}$：把变化的运行工况折算为"额定功率下运行 $t_{VL}$ 小时"。Gebäude-Tool 中全负荷小时出现于三处，语义各不相同：

1. **数据表**（`Std`）：SIA 2024 按房间用途 × 调节方式（einstufig/zweistufig/stufenlos）× 两种基准（Volumenstrom / elektrische Energie）发布的全负荷小时快照；
2. **查表**（`Berechnung LU!K68/K69`）：AHU 引擎按系统实际调节方式（`Lüftung!J`）从 `Std!Q:V` 取 $t_{VL,V}$（风量基准）与 $t_{VL,E}$（电基准），用于年能量折算；
3. **反推**（`Lüftung!K7` 与 `Berechnung LU!J7`）：由 AHU 算出的风机电能 ÷ 风机功率取整得到 $t_{VL}$，作为显示值回写。

## 3.3 公式 1 — 全负荷小时的定义与换算

**数学形式**：

$$
t_{VL,E} = \frac{E_{fan,yr}}{P_{fan,nominal}} \quad[\mathrm{h/a}],\qquad
t_{VL,V} = \frac{\int \dot V(t)\,dt}{\dot V_{nominal}} \quad[\mathrm{h/a}]
$$

**推导**：风机年电能 $E_{fan,yr} = \int P_{fan}(t)\,dt$。若风机功率与风量按 $P \propto \dot V^{2.5}$（见第 4 章 4.4 节）关联，则 $t_{VL,E} = \int P\,dt/P_{nom}$ 与 $t_{VL,V} = \int \dot V\,dt/\dot V_{nom}$ 不同：$t_{VL,E} = \sum_i f_i\, t_{VL,V,i}$ 型的加权结果（电基准对低负荷更敏感）。SIA 2024 数据给出两者，供不同用途取用：
- 风机**电能**计算用 $t_{VL,E}$（`Berechnung LU!K69` 查 R/T/V 列）；
- 风量相关的**热计算**（如新风负荷、混合比）用 $t_{VL,V}$（`K68` 查 Q/S/U 列）。

**单位**：h/a。

**假设**：额定功率 = 设计功率（G6）；负荷率分布按 SIA 2024 假设的逐时运行模式（365 天逐日模型生成，见 Raumdaten `Profile` 表 605–976 行）。

**适用范围**：45 个标准房间用途；调节方式三档。**注意**：`Std` 中 12.11（Kühlraum）全为 0，12.9（Parkhaus）无卫生新风（D47=0）但过程风 2 m³/(h·m²)。

## 3.4 公式 2 — Berechnung LU 按 Regelung 查表

**数学形式**：系统调节方式 $r$（einstufig=1、zweistufig=2、stufenlos=3，`Berechnung LU!I8`）选择 $Std$ 表的列：

$$
t_{VL,V} = Std_{r}[\text{col } 2r-1],\qquad t_{VL,E} = Std_{r}[\text{col } 2r]
$$

（$Std$ 表 Q..V 列对 $r=1,2,3$ 取列 1/3/5 与 2/4/6。）

**工作簿实现**（`Berechnung LU!K68`）：

```
=IF($I$8=1, INDEX(Std!$Q$6:$V$50, MATCH('Berechnung LU'!$B$6, Std!$B$6:$B$50, 0), 1),
 IF($I$8=2, INDEX(Std!$Q$6:$V$50, MATCH('Berechnung LU'!$B$6, Std!$B$6:$B$50, 0), 3),
 IF($I$8=3, INDEX(Std!$Q$6:$V$50, MATCH('Berechnung LU'!$B$6, Std!$B$6:$B$50, 0), 5), FALSE)))
```

`K69` 同构取列 2/4/6。`I8` 由 `I6`（=`Lüftung!J32`，即当前系统的 Regelung）经 `=IF(I6=Begriffe!F205,1,IF(I6=Begriffe!F206,2,IF(I6=Begriffe!F207,3,FALSE)))` 映射（`Berechnung LU!I8`）。

**单位**：h/a。

**推导**：查键为用途名 `B6`（=`Lüftung!B32`，系统服务的用途）；`MATCH` 定位 `Std!B6:B50` 行；`INDEX` 按调节方式取列。这是把"项目选择了什么调节方式"翻译成"用哪组 SIA 全负荷小时"。

**假设**：项目调节方式（`Lüftung!J7`）与 SIA 数据定义的调节档语义一致（einstufig：单速全年额定；zweistufig：67 %/100 % 两档；stufenlos：连续变频）。

**验证**（示例建筑 LA01，Einzelbüro，einstufig）：`K68 = 3900`（`Std!Q10`）✓；`K69 = 3900`（`Std!R10`）✓。

**单元格出处**：`Berechnung LU!I6`、`I8`、`K68`、`K69`；`Std!Q6:V50`；`Lüftung!J7:J22`（Regelung 输入列）、`Lüftung!J32`（模板行）。

## 3.5 公式 3 — 风机年电能与全负荷小时的闭合回路

**风机电能**（`Berechnung LU!H7`）：`=C259/1000`（C259 为区间求和列，单位 kWh → MWh，见第 4 章）。

**反推全负荷小时**（`Berechnung LU!J7`）：

```
=ROUND(IF(G6=0,0, H7*1000/G6), -1)
```

**数学形式**：$t_{VL} = \mathrm{round}_{10}\big(E_{fan}\cdot1000 / P_{fan}\big)$，即年电能（MWh→kWh）除以额定风机功率（kW），并按 10 h 取整。

**Lüftung 表同构公式**（`Lüftung!K7`）：`=IF(H7=0,0,ROUND(I7*1000/H7,-1))`，其中 `H7 = F7*G7/1000`（风量×SFP），`I7 = 'Berechnung LU'!H7`。

**单位**：h/a。**验证**：`H7 = 26.765 MWh`、`G6 = 6.863 kW` → `26.765×1000/6.863 = 3900.0 → 3900` ✓。

**推导**：这是"用电能反算等效满负荷时间"的工程定义（区别于查表值），其与 `K68/K69` 的查表值在示例中一致（3900），因为区间法能量本身就是按运行时间表与 $P\propto V^{2.5}$ 逐时累计的——两种口径互相印证。

**假设**：`ROUND(…,-1)` 的四舍五入为规范（SIA 发布值口径）；G6=0 时输出 0 防除零。

**单元格出处**：`Berechnung LU!H7`、`J7`、`C259`；`Lüftung!F7:K7`（及 8–22 行）、`Lüftung!I32:J32`。

## 3.6 全负荷小时的使用链（全文贯通）

```
Lüftung!J7 (Regelung)  ──►  Berechnung LU!I6 ──► I8 (1/2/3)
                                              │
Std!Q:V (SIA 数据) ◄────  Raumdaten Volll_Lüft（副本）
      │
      └──► Berechnung LU!K68 (t_VL,V) ──► 区间年能量 C254…C259
      └──► Berechnung LU!K69 (t_VL,E) ──► 风机/能耗校验 M70, K70
Berechnung LU!H7 (风机电能) ──► Lüftung!I7 ──► Lüftung!K7 = ROUND(I7*1000/H7,-1)
```

- `K70: =E7*K68/8760`（年风量 × 风量全负荷小时 ÷ 8760 → 年均风量口径的合理性检验值，m³/h）；
- `M70: =G6*K69/K68`（额定功率 × 电/风量全负荷小时比 → 等效平均功率）；
- `Berechnung LU!I20`（Feuchtelast）亦使用 `K70`：`=IF(E52=0,0,(E52*1000)/(3600*(K70/3600)*N23))`（湿度负荷 kg/h ÷（年均风量×密度）→ g/kg 湿度增量）。

## 3.7 移植要点

1. 全负荷小时是**版本化数据**（SIA 2024:2015 / prSIA 2024:2021 / prSIA 2024-C1:2024 三版本并存于 Raumdaten `Volll_Lüft`；`Std` 为 C1:2024 版本快照，`Std!L3` 标注"prSIA 2024-C1:2024 (29 m³/h pro Person)"）。移植数据集应带版本轴。
2. `t_{VL,V}` 与 `t_{VL,E}` 必须成对保留（电基准 ≠ 风量基准）。
3. `ROUND(…,-1)` 取整是规范操作，不是浮点噪声。
4. `Std` 的 C–I 列（Personenfläche、新风、WW）同时服务于第 2 章（体积流量、WW 需求），是同一数据集的三个消费者。
